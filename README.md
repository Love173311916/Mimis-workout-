# 💪 Muscle Build Tracker

A simple, lightweight web app for tracking your sister's 5-day beginner muscle-building workout routine. Logs are saved locally in your browser.

## Features

- ✅ 5-day workout split (Push/Pull/Legs/Full Body)
- ✅ Log weight and reps for each exercise
- ✅ Track progress across days
- ✅ Stats dashboard (sets logged, days completed)
- ✅ Mobile-friendly design
- ✅ Data persists using browser local storage
- ✅ No backend needed

## Quick Start

### Option 1: GitHub Pages (Recommended)

1. **Create a GitHub repository** named `muscle-tracker` (or any name)
2. **Clone it locally:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/muscle-tracker.git
   cd muscle-tracker
   ```
3. **Copy the files:**
   - Copy `index.html` into the repository root
   - Copy `README.md` into the repository root

4. **Push to GitHub:**
   ```bash
   git add .
   git commit -m "Initial commit: Add muscle build tracker"
   git push origin main
   ```

5. **Enable GitHub Pages:**
   - Go to your repository settings → Pages
   - Select "Deploy from a branch"
   - Choose `main` branch and `/root` folder
   - Save

6. **Visit your app:**
   - Your app will be live at: `https://YOUR_USERNAME.github.io/muscle-tracker`

### Option 2: Local File
Simply open `index.html` in your browser. No server needed!

### Option 3: Any Static Host
You can also host this on:
- Netlify (connect GitHub repo)
- Vercel
- Firebase Hosting
- Any static file hosting service

## How to Use

1. **Select a day** - Click Day 1-5 to switch between workout days
2. **Log your sets** - Enter weight (lbs) and reps, click "Log Set"
3. **Track progress** - See all logged sets below the input
4. **View stats** - Bottom section shows your progress
5. **Reset data** - Use the reset button to clear all logged workouts

## Workout Plan

### Day 1: Upper Body - Push Focus
- Barbell Bench Press (3×6-8)
- Incline Dumbbell Press (3×8-10)
- Shoulder Press (3×8-10)
- Lateral Raises (3×10-12)
- Tricep Dips (3×8-10)
- Tricep Pushdowns (2×10-12)

### Day 2: Lower Body
- Barbell Back Squat (3×6-8)
- Romanian Deadlifts (3×8-10)
- Leg Press (3×8-10)
- Leg Curls (3×10-12)
- Calf Raises (3×12-15)
- Leg Extensions (2×12-15)

### Day 3: Upper Body - Pull Focus
- Barbell Rows (3×6-8)
- Assisted Pull-Ups (3×6-10)
- Bent-Over Rows (3×8-10)
- Face Pulls (3×12-15)
- Barbell Curls (3×8-10)
- Hammer Curls (2×10-12)

### Day 4: Lower Body - Variation
- Deadlifts (3×5-6)
- Bulgarian Split Squats (3×8-10 per leg)
- Leg Press (3×8-10)
- Leg Curls (3×10-12)
- Seated Calf Raises (3×12-15)

### Day 5: Full Body / Functional
- Goblet Squats (3×10-12)
- Push-Ups (3×10-15)
- Dumbbell Rows (3×10-12)
- Planks or Ab Wheel (3×30-60 sec / 8-12)
- Dumbbell Step-Ups (3×10-12 per leg)
- Light Cardio (1×10 min)

## Key Tips

📈 **Progressive Overload** - Add 1-2 more reps or slightly increase weight each week

💪 **Rest & Recovery** - Take 60-90 seconds between heavy compound sets, 45-60 sec for isolation

🍽️ **Nutrition** - Eat at a slight calorie surplus (200-300 cal above maintenance) with 1.6-2.2g protein per kg of body weight

😴 **Sleep** - Aim for 7-9 hours per night for muscle recovery

🎯 **Form Over Ego** - Light weight with perfect form > heavy weight with bad form

## Browser Compatibility

Works in all modern browsers (Chrome, Firefox, Safari, Edge)

## Data Storage

All workout logs are saved in your browser's **local storage**. This means:
- ✅ Data persists even after closing the browser
- ✅ No account needed
- ✅ No internet required to view logs (only to first load the page)
- ⚠️ Data is device-specific (won't sync across devices)
